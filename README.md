# 🖥️ Peripheral Monitor

Um aplicativo desktop em Python para monitorar todos os periféricos (USB, Bluetooth, Notebook) em um só lugar.

## 🚀 Como Baixar e Usar
1. Vá na aba **Releases** aqui no GitHub.
2. Baixe o arquivo `Instalar_Peripheral_Monitor.exe`.
3. Execute, instale e pronto!

## 🛠️ Para Desenvolvedores
- **Frontend:** `main.py` (CustomTkinter)
- **Backend:** Pasta `utils/` (Leitura de hardware via PowerShell e Bleak)
- **Banco de Dados:** `utils/devices_db.json` (Reconhecimento de marcas)
